# Brand kit and mockups (real world, BRAND tier)

`brand/` is the **real-world** brand (BRAND tier in LICENSING.md, not licensed; TRADEMARKS.md).
In-universe Avenell material is a different job (skill `cyc-brand-history`). Authorities:
`brand/BRAND_KIT.md` (positioning, voice, Erg usage, owner gate), `brand/AI_TELLS.md` (the
standing checklist), `brand/tokens.json`, `brand/mockups/README.md`. Tests: `tests/brand.test.ts`.
The live site (`site/`, `tests/site*.test.ts`) and its product art (`art/blender/`) follow the
same hard rules. Nothing is published without the release gate (skill `cyc-licensing-and-release`).

## Before designing anything
- **Read `brand/AI_TELLS.md` first** (13 sourced tells: gradients, glows and halos, purple UI,
  glass, blanded monoline wordmarks, no optical corrections, identical radii and card grids,
  centred two-tone heroes, sparkles and orbs, category clip-art, centred badges, vibe copy, fake
  texture, one-image delivery). The owner rejected a concept as "clearly generated by AI"; the
  round-1 mockups hit tells 2, 6, 7 and 11. The test rejects gradients, halos, glass and blurred
  shadows in `brand/mockups/src/page.css` and any non-token colour in logo files. For the site,
  tells 2, 3 and 12 are narrowed, not dropped: glow only from a lamp, beam or screen, glass only
  as a real tube or bezel, texture only on a material (`BRAND_KIT.md` §6a; DECISIONS [brand/site] (4)).
- AI-drafted logo concepts are drafts: a human designer redraws them under a written assignment
  before any trademark filing (skill `cyc-licensing-and-release`).

## Sources, not pictures
- **Commit the source of every mockup next to its PNG**: HTML in `brand/mockups/src/pages.ts`,
  styles in `page.css`, renderer scenes in `stage.ts`, and `build.ts` shooting them with
  Playwright (`node brand/mockups/src/build.ts [prefix,...]`). Round 1 kept its HTML in `.tmp/`
  and lost it; round 2 had to re-create the stage before it could change one mockup.
- `build.ts` writes `src/shots.json` with sha256(html) and sha256(png) per shot, and the test
  recomputes both from the pure page source. Keep page HTML path-independent (`@logo/`, `@pic/`
  placeholders) and CRLF-normalised so the hash is the same on every checkout. Fonts are local
  stand-ins, so rebuild and commit on one machine.
- **Colours only through the token stylesheet** (ramp steps as `.r0`–`.r7` classes), never
  inline `style` hex, gradients or radii: the AI-tells test rejects inline values.

## Every picture is real or captioned
- An emulator picture in a mockup is a real ROM frame with provenance: ROM, SHA-256, input
  (replay or run-length pads), frame and `Machine.hash()` in `brand/mockups/frames.json`; the test
  rebuilds the ROM and replays to that hash (~9 s; an edited hash fails).
- A live renderer picture (the site's light-field demo) is proved "what the machine draws" against
  a Machine on a blank, locked-out ROM with `m.video` set to the scene's VideoState and one
  `runFrame`; the probe latch is then `m.bus.read16(0xF058)` (tests/site-lightfield.test.ts).
- Scene-kit renders are allowed only captioned "Barndoor line renderer", never as gameplay. A
  test that every renderer picture carries its caption found a gap in an accepted round-2
  mockup (hero-mobile).
- **Read every shot after building** (RECURRENCE of skill `cyc-show-human` §3): wrong captions
  and text overflow are only visible in the image (a caption said puzzles 08/07/09 over frames
  showing 07/08/09; three mobile pages overflowed their pinned height).

## HTML, CSS and SVG pitfalls in Playwright shots
- A `position: fixed` nav paints across the middle of every element screenshot: inject
  `nav{position:absolute}` before shooting sections.
- A `<div>` inside a `<p>` silently closes the paragraph and drops its class styles: use `<span>`
  for inline decorations.
- A later `position: relative` element paints over an earlier absolutely positioned one: scope
  overlay selectors to `body > .x`, not a class that also matches inner containers.
- An SVG loaded with `<img>` resolves `currentColor` to black and keeps its ids private; inlining
  several SVGs in one page makes shared ids (`mask`, `clipPath`) collide. Use `<img>` for logo
  comparison sheets (`brand/src/compare.ts`).
- Logo file suffixes differ by kind: `-small` is a square favicon cut for a mark but a wide small
  optical size for a wordmark; hygiene tests must not force a square on the wordmark.
- Playwright test pitfalls for site widgets (init scripts on `setContent` pages, keyboard Tab
  order): skill `cyc-verify`, pitfalls.md "Browser test races".

## Site product art (Blender, `art/blender/`)
Read `art/blender/README.md` first (`python art/blender/build.py`; checked by tests/site-art.test.ts).
- Light passes the site stacks with `plus-lighter` add encoded values: grade each pass only
  linearly and publish the beauty as clip(sum of the encoded passes); a separately rendered
  beauty never matches (post.py; the site-art MAE check on Chromium's decode).
- Keep instruments apart with light linking (rim → products only, pool → floor, pad and cable) so
  passes stay spatially separate and their sum doesn't blow out (scene.py `product_only()`).
- Boolean-cut hard-surface shells get a WEIGHTED_NORMAL (face area, keep sharp) before the
  modifiers are applied, or smoothing fans streak across the n-gons (lib.py `bake(weighted=True)`).
- Set the render resolution before projecting callout anchors: `world_to_camera_view` uses the
  scene aspect (the first hero anchors were off at a 16x16 placeholder size).

## Real-world names
- Product names and mascot limits ("-Erg" compounds, helmeted visor mascots): skill
  `cyc-licensing-and-release` "Rules".
- Site timeline slips must not invent in-universe document numbers: HED-nnnn is the Home
  Entertainment Division series (from 1986), so a 1974 event can't carry one. Use neutral tags
  (COMPANY, MEMO, PRESS) or registered numbers only.
